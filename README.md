# Claude Code Demo

This is a demonstration repository for Claude Code training and examples.

## Installation

### Prerequisites

- Node.js (v14 or higher)
- npm (usually comes with Node.js)

### Setup

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd claude-code-demo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Project Structure

- `CLAUDE.md` - Project instructions and guidance for Claude Code
- `screenshot.js` - Screenshot utility script
- `configs/` - Configuration files directory
- `docs/` - Documentation directory
- `examples/` - Examples directory
- `samples/` - Sample files directory

## Dependencies

- **playwright** (^1.56.0) - Browser automation for screenshot functionality

## Usage

This repository serves as a demo for Claude Code functionality. The main features include:

- Screenshot capabilities using Playwright
- Claude Code integration examples
- Training documentation and guides
